## Selected Research

### [Preservation-First Malware Detection](https://github.com/eOluwumi/Preservation-First-Malware-Detection)
Ongoing research into structural fidelity in binary-derived malware image representations. The work examines structure-preserving inputs, zero-padding, conventional resizing, class-imbalance strategies and the implications of preprocessing choices for malware detection and reverse-engineering integrity.

### MSc Research — Intelligent System for Generic Malware Detection
Developed and investigated a deep-learning framework involving MalwareAutoEncoder (MAE), a GAN-based generative approach (MalGen), and an attention-enhanced residual-network-based Intelligent Malware Detection System (iMDS). The research used the Malimg dataset and a VirusShare-derived dataset to study malware representation, augmentation and classification under class imbalance.
